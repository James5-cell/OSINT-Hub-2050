# OSINT Hub 产品优化说明

## 定位

面向不熟悉 OSINT 的普通用户，提供公开信息查证教育和资源推荐。
核心价值是把日常关键词转成合适的来源和操作起点，降低寻找工具的成本。

用户输入的是查证对象或线索；输出是资源推荐，不是对象的调查结果。
网站不自动把姓名、公司名称等输入传送到推荐网站。

## 已落实的变化

1. 首页以搜索为主要入口，保留公司、人名、网站、图片四个快捷入口。
2. 移除首页完整分类、数量统计和长工作流展示。
3. 主导航收为找资源、认识 OSINT、工具目录。
4. 搜索结果先显示五个资源，按需展开更多。
5. 每个有操作指南的推荐说明推荐理由、第一步、覆盖范围和来源局限。
6. 用查证目的、地区、免费、新手网站筛选缩小范围；筛选写入 URL。
7. 新建中英双语入门页，以公司背景查证示例连接教育和工具使用。
8. 完整工具目录和原有详细流程保留为次级入口；旧分类链接仍可使用。
9. 精简设置和关于页面，更新网站定位、元信息和机器可读入口。

## 数据与搜索

参考 Meilisearch 的文档索引、同义词、筛选、排序等概念，使用自己的
静态数据和浏览器匹配逻辑。没有引入 Meilisearch 服务或其运行依赖。

数据来源分为工具记录、调查对象、任务目的和操作指南。构建脚本检查引用
及内容，并生成可随网站发布的 JSON 数据库和索引。开发和构建都会自动生成。

第一版包含 10 类对象入口、19 种目的、29 份资源操作指南。
原始数据有 122 条记录，本次补充 3 个地区企业登记入口。
排除现有死亡或停用标记后有 123 条可搜索记录。
资源记录的原始审核状态保留；本次新增的说明不代表重新核验了外部网站。

排序优先精确工具名称，其次带指南的任务推荐，再展示所有对象类型匹配资源。
有无指南不影响对象搜索的收录，审核标记和注意事项保留。
选择具体目的后，会缩小到明确标注适用该目的的资源。
新增官方资源采用来源文档确认标记，不冒充人工完成端到端审核。
通用对象关键词不会仅因工具名称包含相同词就获得高排名。
英文别名采用词边界匹配，中文采用明确的简繁别名。
网址、电子邮件、有效 IPv4 地址和 @用户名可以识别对象类型。
姓名本身不作身份推断；无法识别的输入提供对象选择和空结果引导。

## 当前边界

- 地区筛选只使用明确标注的范围，未标注的资源会被排除。
- 本次补充中国大陆、台湾和香港企业登记入口，保留待审核状态。
  已参考官方文档；大陆和台湾站点阻挡自动存取，完整查册流程未测试。
  官方来源入口的推荐理由与访问限制单独记录，不能视为数据准确性保证。
- 跨地区资源并不保证涵盖用户输入的每个对象，需要核对来源覆盖。
- 费用和访问条件沿用工具记录，以来源网站当前说明为准。
- 字词识别和资源名称单字符容错是轻量规则，不是完整语义搜索。
- 工具目录中尚未添加操作指南的记录仍使用原有介绍和审核标记。
- 详细工作流保留既有内容，支持英文和繁体中文。

## 后续维护

优先根据真实的无结果查询补充关键词和当地可靠来源，再扩充资源数量。
新资源必须提供明确用途、适用范围、操作起点和局限，避免只增加外部链接。

修改源数据后，在 apps/web 运行：

```bash
npm run search:build
npm run test:search
npm run typecheck
npm run build
```

生成文件可直接随静态网站发布。更新不需要维护独立搜索服务。

## 2026-10-03：书籍评估后的实施

- 当前生成库：126 个有效资源，14 类输入入口，23 个目的，32 条使用指南。
- 所有有效资源都有输入、输出、任务作用与覆盖元数据；这些是编辑整理，不是全站实时可用性审计。
- 人物结果优先展示姓名入口，补充线索、分析、研究准备可分别浏览。
- 目的筛选兼容能力记录，不再要求每条资源先有完整指南；地区未知保留并提示。
- 新增 Google Search、Google Scholar、Fact Check Explorer，并核对上述来源与 InVID 官方说明。
- 新增 Google 查询模板、六项基础教学、四个判读练习及本地查证记录（自动保存、复制、Markdown 导出）。
- 原有 11 套完整双语流程继续提供深入阅读；修正“主要为英文”的标识。
- 没有引入外部搜索服务或个人资料采集，继续使用本地构建索引。

设计依据与详细内容参见 `docs/osint-book-project-review.md`。未知地区与覆盖限制仍需后续维护；不把旧书中的链接当作已验证资源。

验证：搜索与查询模板回归测试、生产构建，以及浏览器中的用途筛选、练习反馈、本地记录恢复与导出、375px 手机布局和双语显示。

## 实作任务补充

新增 `/tasks`，十个日常问题连接优先来源、替代路径、四步操作、无结果时的策略和查证记录。公司、人物公开职业资料、图片案例使用明确标注的虚构材料练习比较证据；新闻案例练习来源独立性。首页、学习页及适用的搜索入口可以进入任务。

任务资料位于 `apps/web/data/search/tasks.json`。操作完成标记仅为本次浏览进度，不能作为系统已核实结论的证明。查证记录可主动套用任务问题，原有证据字段保持不变并提示重新检查关联性。

## 维护方向确认

用户确认旧抓取流程无法运行。当前产品不依赖该流程，后续工作聚焦工具目录、资源覆盖、推荐准确度与教学实作。支持的维护方式为直接整理本地资源、能力、指南与任务资料，再由 `build_search_database.mjs` 校验并生成目录和搜索索引。旧抓取与 AI 补充脚本只保留为历史参考，不作为维护前提；本次没有删除历史文件，也没有尝试修复或运行旧抓取流程。

## 资源、推荐与维护校验补充

本轮补充台灣事實查核中心与 Full Fact，并核对官方网站；为 OpenSanctions、ICIJ Offshore Leaks、PACER 补充来源、操作与误判限制。当前为 128 个有效资源、37 条使用指南。所有任务的优先来源与替代来源均有使用指南；Mapillary 指南为编辑整理，没有标记为官网核验。官网说明分别见 https://tfc-taiwan.org.tw/ 、https://fullfact.org/about/ 、https://www.opensanctions.org/docs/ 、https://offshoreleaks.icij.org/pages/about 、https://pacer.uscourts.gov/find-case 。

修正明确选择对象时精确工具名被一般推荐覆盖的问题；新增直接输入与已标注地區筛选。地區未知默认保留；新闻来源的地區描述编辑重點，不是访问限制。十个教学任务均有对应的证据判断练习，反馈说明结论范围及后续查证方向。

生成前自动检查任务引用、输入枚举、翻译、答案位置与日期；输出本地 maintenance-report.json，列出缺指南、地區未知与待审记录。没有运行旧抓取脚本。

## 配套目录与旧流程清理

加入参考书配套 OSINT.link 目录，明确其为资源导航而非已核验的对象资料库。旧抓取、AI 补资料、一次性添加脚本、对应测试及原始快照集中归档至 archive/legacy-import；旧 weekly-sync 工作流移出启用目录。保留当前校验、索引生成与链接检查。公开 llms-full.txt 改为从现有资源数据库生成，移除重复维护的旧清单与过时描述。
