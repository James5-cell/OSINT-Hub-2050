# Archived import pipeline

Historical upstream scraping, AI enrichment, one-time additions, input snapshots
and Python tests. This workflow is reported nonfunctional and is not supported.
It is not called by the website and the old GitHub sync workflow is no longer
in `.github/workflows`. Files are retained for reference, not automatic execution.

Paths and dependencies describe the historical checkout; archived scripts may
not run here. Current resources live in `apps/web/data`, with validation and
index generation in `scripts/build_search_database.mjs`.
